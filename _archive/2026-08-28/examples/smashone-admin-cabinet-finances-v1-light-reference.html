Period filter

Six chips (Today · 7d · 30d · 90d · YTD · custom). Active state combines gold tint + 1px gold border + weight 600 — so the indicator passes WCAG 3:1 without relying on hue alone. Clicking re-fetches KPIs, repaints the area chart, recomputes deltas vs the matched prior period.

KPI drill-down

Each tile is a link. Click Revenue · 30d → opens the revenue breakdown view with the donut as filter; click Refunds → opens the refunds queue filtered to the same period. Hover lifts −2px, restoring on mouse-out — same 200ms easing used everywhere.

Area chart hover

Crosshair line + filled green dot snap to the nearest day; tooltip shows date, income, refunds (red, hidden when zero), and Δ vs the prior day. Last point pulses gently — “now” signal. Refund spike days carry red circles sized by amount, so May 04 ($290 spike) reads at a glance.

Donut + table

Donut segments use the IBM colorblind-safe palette and lift +4% on hover. Each row in the customers table is the row click-target → opens a right-side drawer with full customer record, plan history, refund history, and Stripe TX log. ⌘K opens the global palette from anywhere.
