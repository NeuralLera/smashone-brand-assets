Responsive behavior

  • Sidebar collapses to hamburger drawer — slide-in from left, 320ms ease-open, scrim with blur(6px).
  • Top bar shrinks to brand + Partner pill + bell + avatar. Search opens as a full-sheet overlay when tapped (⌘K stays semantic).
  • Greeting compresses to name + one-line outcome, period chips become horizontally scrollable.
  • Payout bar keeps its left gold edge, drops the ghost CTA — tap card to open the Stripe-hosted sheet.
  • 4 KPI tiles stack 2×2 at 375 → 1-up below 360. Hero tile (May earnings) reads first.
  • Chart keeps 12 bars but drops y-axis labels; “View as table” link surfaces on tap.
  • Transactions feed becomes a compact row pattern (icon · 2-line title · amount), full-width.
  • Right-column cards (Top client / Funnel / Stripe) move below the feed as the next vertical group.
  • Primary “Copy my referral link” CTA pins to a sticky bottom action bar on scroll (44×44 hit target).

Touch targets & accessibility

  • All interactive controls ≥ 44 × 44 CSS px (chips, icon-buttons, feed rows).
  • Focus ring 2 px gold + 4 px offset survives in light theme.
  • Status uses icon + color + label (3-channel) — never color alone.
  • prefers-reduced-motion drops chart fade-in, drawer slides and KPI hover lifts.
05 · Notes

Decisions outside the brief

Flag for Phase 4 polish review

Things to confirm or adjust

  • Bar chart implementation. Rendered native (CSS grid + SVG-free bars) instead of Tremor — keeps the bundle empty for a static concept and avoids React-tree noise. For Phase 4 production, Tremor is the canonical choice per iron rule 17; switching is a single component swap.
  • Chart timeline. Brief said 12 months but Sarah's tenure runs Feb 2025 → May 2026 (16 months). I rendered 16 bars so the empty-pre-tenure rhythm is visible at 4% opacity. Easy to crop back to 12 if you want strict «last 12».
  • Greeting time-of-day. Hard-coded "Good morning" — should resolve from the user's local hour client-side (`new Date().getHours()`).
  • Wordmark monogram. Used a small gold tile + Lucide zap glyph as the "S⚡O" fallback — feels brand-correct but isn't a literal three-character lockup. Confirm or swap for the asset-repo tile when it ships.
  • Notifications. Single bell with a red dot for 3 unread — no popover spec'd in the brief. Click opens a side-sheet (out of scope for this concept).
  • Path 3 in transactions feed. Sarah has no Path 3 events on the May log — Path 3 chip lives in the component gallery only. If you want a Path 3 sample event embedded, I'll add one.
  • Hero KPI delta tooltip. Tooltip copy (setup / L1 / L2 breakdown) is in the Info icon's title attribute — interactive tooltip is one click of polish away.
  • Avatar style. Used a 9-px rounded square with cream `#f0ece2` background + gold-text initials, matching the Aibro «АМ» / DEMOBIZ «МБ» tile pattern. Brief said "neutral cream"; this reads warmer than `#f5f5f5` which felt cold against the gold accents.
  • Sidebar identity card. Made it a standalone elevated card rather than inline text — distinguishes the partner identity from the brand identity above it, mirrors the «ИП Мальцев» tile.
  • Mobile drawer interaction. Slide-in from left, 260ms ease-open, dismiss on scrim tap. Locked-body-scroll while open. Not built in this concept (no JS state) — listed for Phase 4.
  • "View as table" link. Stubbed as a link in the chart footer. Real implementation expands an inline data table per iron rule 17.
