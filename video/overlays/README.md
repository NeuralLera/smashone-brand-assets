# `video/overlays/` — кит наложений для роликов героев (9:16, дизайн-система SmashOne)

Слово владельца 03.09.2026: «сборка в нашей дизайн-системе — шрифты наши, золото наше, логотипы, плашки где уместны,
акценты в эффектах». Премиум, ничего лишнего: без рамок и декора. Первый писатель — Мира; сборка детерминированная —
`SMM-Hub/design/scripts/video_overlay_kit.py` (пересобирает всё из `SPEC.json`-параметров, ничего не рисуется руками).

Raw-база: `https://raw.githubusercontent.com/smashone-corp/smashone-brand-assets/main/video/overlays/`

## Токены
| Что | Значение |
|---|---|
| Шрифт | **Onest** (variable 100–900, OFL) — `fonts/Onest-Variable.ttf`; системные шрифты не используются |
| Золото | `#B08930` |
| Текст на золоте | `#1A1917` (a11y-канон: на золоте только тёмный текст) |
| Крем (светлый фон) | `#F7F6F2` |
| Чернила (тёмный фон) | `#1A1917` |
| Скругление плашек | 28 px на кадре 1080×1920 (ДС r-xl в масштабе 9:16) |
| Поля кадра | 72 px от левого/правого края |

Все PNG — 1080×1920 с альфой (кадр целиком, прозрачный фон), кроме чипа и знаков-водяных (отдельные элементы) и
финальных карточек (непрозрачные). Класть поверх видео без масштабирования: `overlay=0:0`.

## 1. Нижняя плашка имени/роли
- `lower-third-sloane-9x16.png` — «Sloane» / «SmashOne AI SMM Manager».
- `lower-third-blank-9x16.png` — та же плашка без текста (ширина 560): Дон подставляет имя и роль другого героя.
- Геометрия (из `SPEC.json`): плашка x=72, y=1476, h=180, золото `#B08930`, радиус 28; ширина = текст + 2×44, минимум 560.
  Имя — Onest **700**, 60 px, `#1A1917`, x=116; роль — Onest **500**, 34 px, `#1A1917`, под именем с зазором 10; обе строки
  центрированы по вертикали внутри плашки.
- Своё имя/роль ffmpeg-ом поверх пустой плашки (ширина 560 хватает на имя до ~14 знаков и роль до ~26 знаков при этих кеглях;
  длиннее — пересобрать генератором с `--slug --name --role`):
```
ffmpeg -i clip.mp4 -i lower-third-blank-9x16.png -filter_complex "\
[0][1]overlay=0:0,\
drawtext=fontfile=fonts/Onest-Variable.ttf:text='Sage':fontsize=60:fontcolor=0x1A1917:x=116:y=1476+(180-(60+10+34))/2,\
drawtext=fontfile=fonts/Onest-Variable.ttf:text='SmashOne AI Video Maker':fontsize=34:fontcolor=0x1A1917:x=116:y=1476+(180-(60+10+34))/2+70" out.mp4
```
(`drawtext` не умеет вес variable-шрифта — для точного 700/500 лучше пересобрать PNG генератором; сниппет — на случай, когда нужно быстро.)

## 2. Чип «AI-generated presenter»
- `chip-ai-presenter.png` (1×), `chip-ai-presenter-small.png` (0.75×) — белая плашка, золотые буквы Onest 700 30 px:
  тот же стиль, что бейдж «AI» аватаров v2 (29.08).
- `chip-ai-presenter-9x16-topright.png` — уже поставлен в кадр: 72 px от правого края, 96 px сверху. Класть `overlay=0:0`.
- Показывать весь ролик или первые 3 с — решение монтажа; убирать нельзя (маркировка ИИ-ведущего).

## 3. Финальная карточка (2–3 с)
- `endcard-9x16-light.png` — крем, чёрный знак 300 px (y=700), «smashone.us» Onest 700 76 px (y=1064), слоган
  «Hire an AI. Enjoy life.» Onest 500 44 px, чернила .64 (y=1168). **Основной вариант (light-first ДС).**
- `endcard-9x16-dark.png` — чернила `#1A1917`, золотой знак, кремовый текст — для роликов, где светлая карточка «вспыхивает».
- Без цен, чисел и дат — по канону витрины.

## 4. Знак-водяной для угла
- `watermark-mark-{gold,white}-{96,160}.png` — знак на альфе, два размера, два цвета (золото для светлого кадра, белый для тёмного).
- Позиция: угол, 72 px от краёв; прозрачность задаёт монтаж (рекомендация `colorchannelmixer=aa=0.7`). Не ставить в тот же угол, что чип.

## Что НЕ входит (осознанно)
Рамки, подложки под весь кадр, градиентные виньетки, анимированные акценты — «премиум, ничего лишнего». Эффекты — в монтаже,
цвет акцента — золото `#B08930`.
